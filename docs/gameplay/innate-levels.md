# Innate power levels

Only a cast whose authoritative source is `INNATE` uses this table. A grimoire (`SPELL`), crystal (`CRYSTAL`), Shadow Sword, Heavenly Partisan, or other artifact (`ARTIFACT`) always starts from its own authored values. Invalid levels clamp to 0–10 and unknown actions remain at an unranked 1× profile.

Between levels 0 and 10 each value advances deterministically toward the capstone below. Transformations arrive at levels 3, 6, 9, and 10. Destruction is a bounded 0–10 work tier: it changes crater/scar radius, hardness, and per-impact work budgets without using an unbounded vanilla explosion.
