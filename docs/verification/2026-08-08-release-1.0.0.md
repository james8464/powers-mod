## Runtime smoke tests

### Dedicated server

An isolated server was started with a new temporary universe and an ephemeral game port:

```text
./gradlew runServer --args="nogui --universe /tmp/powers-final-crystals.diLhGB --port 0"
```

The server reached `Done (1.837s)`, loaded POWERS 1.0.0, registered 27 powers, loaded both 28-node rank mazes, created the Middleworld, Light Realm, and Dark Realm, and stopped with exit code 0. All dimensions saved successfully.

RCON port 25575 was already owned by a separate development server, producing a non-fatal bind warning. The isolated game server remained operational and accepted a normal `stop` command.

### Client resources

The development client completed resource reload and initialized its sound and rendering systems. POWERS emitted no missing-model, missing-texture, invalid-animation, or unused-animation-frame warnings. Remaining diagnostics were vanilla development authentication and Apple/Metal shader messages, not POWERS asset failures.

## Release-scope checks

- All eleven crystals have active, cooldown-safe abilities; no crystal or progression-artifact crafting recipes were added.
- The only POWERS recipes are the amethyst ward and imported-food cooking/smoking recipes.
- The vulnerable mindscape body uses Minecraft's native player-like mannequin, with incoming damage mirrored to the travelling player.
- Invasive mind powers require consent, and teleportation, possession, projection, freezing, summoning, and area effects have bounded or explicit counterplay.
- Vanilla loot tables are extended additively instead of replaced.
- No known build, resource-loading, registry-startup, or dedicated-server startup errors remain.

Multiplayer balance and subjective visual feel should still receive normal playtesting on the intended server; those experiential checks are not substitutes for the automated and startup gates above.
