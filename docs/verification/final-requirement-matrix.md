## Release interpretation

The gates prove deterministic rules, registry/resource integrity, protocol bounds, live critical paths, dedicated startup, and bounded synthetic multiplayer load. They cannot guarantee the subjective feel of every effect in every third-party modpack, so the intended server should still use a backed-up staging world for balance tuning and catastrophic-terrain acceptance.
