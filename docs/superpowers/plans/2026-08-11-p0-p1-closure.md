# P0/P1 closure implementation plan

**Goal:** Implement and prove every P0/P1 item in `docs/planning/IMPROVEMENT_BACKLOG.md`, remove only accepted rows, and publish directly on the sole `main` branch.

**Method:** Work test-first on the authoritative server boundaries. Reuse existing production mechanisms where an item is already partly implemented, but add executable acceptance evidence before closing it. Keep safety, persistence, workload, networking, visual, and accessibility policies explicit.

## Phase 1 — Release foundations

- Consolidate Git onto `main`; delete all other local/remote branches.
- Establish the clean build/GameTest/resource/soak baseline.
- Add Java-25 CI lanes, isolated test result directories, protocol handshake, packet fuzzing, mutation testing, save-migration fixtures, and release evidence scaffolding.
- Covers `NET-001`, `NET-002`, `QA-001`–`QA-003`, `QA-006`–`QA-008`, `COR-001`, `INT-001`, `SHD-001`.

## Phase 2 — Correctness and lifecycle

- Unify staged casting transactions and fault rollback.
- Prove body/avatar death ordering, Time Freeze ownership, Celestial Ruin journaling, artifact authorization, lifecycle outcomes, persistence/rejoin, consent overrides, names, forcefields, Crucible atomicity, legacy gamemode, world-border/missing-dimension recovery, and foreign attributes.
- Covers `COR-002`–`COR-016`, `INT-003`, `INT-004`.

## Phase 3 — Performance and server observability

- Index natural amethyst; instrument indexes; adapt visuals; coalesce/pool FX data; persist force frontiers; enforce fair quotas and chunk-ticket backpressure.
- Add real dedicated-server bot profiling at 10/50/100 players and publish p95/p99 results.
- Covers `PERF-001`–`PERF-009`.

## Phase 4 — Gameplay, content, and systems

- Prove every innate rank, spell, crystal, item, loot route, and collision family.
- Add minimum terrain signatures, boss resistance feedback, grimoire contents, Celestial Ruin dry-run/preview, alternative rank milestones, realm worldgen/templates, and tactical guardian AI.
- Covers `PWR-001`–`PWR-003`, `SPL-001`, `SPL-002`, `SPL-006`, `CRY-001`, `CRY-002`, `PRG-001`, `PRG-002`, `ART-001`, `ART-002`, `WRLD-001`, `WRLD-002`, `MOB-001`, `MOB-002`, `SHD-002`–`SHD-005`, `SHD-017`, `INT-002`, `NET-003`.

## Phase 5 — Client presentation and acceptance

- Add screenshot harness/goldens, all GUI/HUD permutations, configurable vanilla-aligned HUD placement, revised energy symbols, semantic-particle audit, near-camera FX exclusion, and complete manual checklist.
- Covers `UX-001`–`UX-003`, `VFX-001`–`VFX-003`, `QA-004`, `QA-005`.

## Phase 6 — Closure

- Run clean full build, all JUnit/GameTests, server/client smoke, screenshots, save migration, mutation, long restart soak, 10/50/100 profiling, resource/audit/doc checks, and manual checklist.
- Remove accepted P0/P1 rows from the backlog; retain any unproven row with evidence explaining why.
- Regenerate documentation/manifests, update README/changelog/release report, commit directly to `main`, push, and confirm GitHub has only `main`.
